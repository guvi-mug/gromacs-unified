# Prebuilt packages

Download the wheels, sample simulation inputs, and checksum file from
[GROMACS Unified v0.2.0](https://github.com/guvi-mug/gromacs-unified/releases/tag/v0.2.0).
The binaries are release assets; they are not stored in Git history.

The committed [v0.2.0/SHA256SUMS](v0.2.0/SHA256SUMS) pins the exact asset bytes.
See [prebuilt setup instructions](../INSTALLATION.md#install-a-prebuilt-release)
for Python/uv installation, Windows runtime requirements, Linux ABI requirements,
and the supported GPU architecture. Both wheels include the CPU and CUDA
engines behind one CLI and Python library.
